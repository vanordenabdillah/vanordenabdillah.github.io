RANSAC Object Segmentation

This page is a work in progress. Come back later.
Python RANSAC Point Clouds Computer vision

A segmentation pipeline that separates individual objects sitting on a table from the surface they're resting on, using RANSAC to fit and remove the dominant plane.

Overview

The pipeline takes in a scene of objects sitting on a table and separates the objects from the tabletop itself. RANSAC (Random Sample Consensus) is used to fit a plane model to the dominant flat surface in the scene - repeatedly sampling small sets of points, fitting a candidate plane, and scoring it by how many points fall within a distance threshold (inliers) - which makes it robust to noise and to the objects themselves, which show up as outliers to the plane model.

Once the table plane is identified and removed, the remaining points are clustered to isolate each object individually, giving a clean per-object segmentation that downstream tasks (like object recognition or grasp planning) can use.
