This page is a work in progress. Come back later.
Python TensorFlow CNN Machine learning

An image classifier that distinguishes between two object classes, built and trained with TensorFlow.

Overview

The model takes an input image and classifies it as either [object A] or [object B]. It's a convolutional neural network trained on a labeled dataset of images for the two classes, with a standard train/validation split used to tune the model and check it's generalizing rather than memorizing the training set.
