Monte Carlo Localization

This page is a work in progress. Come back later.
Python Webots Particle Filter Robotics / simulation

A particle-filter-based localization system that lets a differential drive robot estimate its own position in the Webots simulator.

Overview

The robot doesn't know its own position ahead of time, so it maintains a set of "particles" - weighted guesses of where it might be, each with an (x, y, heading) - and refines that belief over time. On every timestep, particles are moved according to the robot's motion model (with noise, to account for wheel slip and imperfect actuation), then re-weighted based on how well each particle's predicted sensor reading matches what the robot's actual sensors observe.

Particles are periodically resampled, favoring higher-weighted (more likely) particles, which lets the belief distribution converge on the robot's true position over time even though no single particle is ever told the "right" answer directly. The differential drive kinematics (independent left/right wheel speeds) are what define the motion model used to propagate each particle.
