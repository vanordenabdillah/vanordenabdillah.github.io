RAG Chatbot

This page is a work in progress. Come back later.
Python RAG Team project Web app

A retrieval-augmented generation chatbot built with a small team, deployed as a web app on PythonAnywhere.

Overview

The chatbot answers questions grounded in a specific set of documents rather than relying only on what the underlying language model already knows. Incoming questions are embedded and matched against a vector store of chunked source documents; the most relevant chunks are retrieved and passed to the language model as context alongside the question, so answers are grounded in and can cite the actual source material instead of the model's own possibly-outdated or hallucinated knowledge.
